# 🛒 E-Commerce Project

A full-stack E-commerce web application built using modern web technologies. This project includes Admin Panel, Client (User Interface), and Server (Backend API) to manage products, users, orders, and overall shopping functionality.

---

## 🚀 Features

### 👤 Client (User Side)
- Browse products
- Product details page
- Add to cart
- Responsive UI
- Modern design

### 🛠️ Admin Panel
- Manage products
- Add / Edit / Delete products
- Dashboard interface
- Admin controls

### ⚙️ Server (Backend)
- REST API
- Product management
- User handling
- Database integration

---

## 🧑‍💻 Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB (or your database)
